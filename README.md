# 🌿 Greenden - Indoor Plants for Interior Decor

Greenden is a responsive **indoor plant website** designed for people who want to bring a fresh, natural, and beautiful look to their interior spaces. The website showcases a collection of plants suitable for home and office decoration.

## 🚀 Live Demo

[View Greenden Website](#)

## ✨ Features

- 🌱 Collection of indoor plants
- 🏡 Plants suitable for interior decoration
- 🪴 Modern and attractive plant showcase
- 📱 Fully responsive design
- 🔍 Easy-to-browse product sections
- 🎨 Clean and minimal user interface
- ✨ Hover effects and interactive elements
- 📞 Contact section for customer enquiries

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **Tailwind CSS** – Styling and responsive design

## 🎨 Tailwind CSS

Tailwind CSS is used to create the website's:

- Responsive layouts

- Spacing and sizing
- Colors and typography
- Hover effects
- Buttons and cards
- Mobile-friendly layouts

## 📱 Responsive Design

Greenden is designed to provide a smooth experience on:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet

## 🌿 About the Project

Greenden aims to provide a simple and visually appealing platform for discovering **indoor plants for interior decoration**. The website focuses on combining greenery with modern interiors to create a fresh, calm, and natural atmosphere.

## 🎯 Project Purpose

This project was created to practice **HTML and Tailwind CSS** while building a real-world responsive website for an indoor plant and interior-decoration concept.
